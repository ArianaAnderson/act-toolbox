# Auditory Core Test (ACT)

The Auditory Core Test is a research software platform under development at the University of California, Los Angeles for remote assessment of cognition, psychiatric symptoms, and vocal affect.

## Project information

- **Principal Investigator:** Ariana Anderson
- **Institution:** University of California, Los Angeles (UCLA)
- **Research network:** National Neuropsychology Network (NNN)
- **Funding:** Brain & Behavior Research Foundation (BBRF), Grant #34030

## Current status

This repository contains the public ACT landing page and front-end prototype. The site does not currently collect, upload, or store participant recordings or research data.

## Planned assessment areas

- PTSD and related symptom measures
- Verbal fluency and Animal Naming
- Working and episodic memory
- Executive function and attention
- Voice-based measures of affect

## Website

The public website is designed for GitHub Pages and is served directly from the repository's `main` branch.

## Data and security

Do not commit participant information, recordings, credentials, API keys, or unpublished research data to this repository. A future scoring service should be deployed separately in an institutionally approved environment.
